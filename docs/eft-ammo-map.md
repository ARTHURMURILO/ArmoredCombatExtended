## Regenerating

```sh
python3 tools/gen_eft_ammo_map.py
```

The generator only uses the Python standard library, reads the pack sources in sorted order and writes the three files above. Output is deterministic: re-running it produces byte-identical files. `--check` verifies the checked-in outputs are current:

```sh
python3 tools/gen_eft_ammo_map.py --check
```

## How the generator works

1. **Config**: parses `sh_config.lua` for `C.CaliberByToken`, `C.MassRatioByToken`, `C.ShellCaseMass`, `C.ShotgunBores` and `C.Defaults.FallbackMassRatio`. The tables are the single source of truth; the generator fails if they are missing or truncated.
2. **Scan**: walks `Weapon_pack_extracted/eft_extract/<workshopid>/lua/...` in sorted order and splits each `.lua` file on `ARC9.LoadAttachment(ATT, "eft_ammo_...")`, keeping blocks whose `ATT.Category` contains an `eft_ammo_*` token. This catches the `attachments_bulk/eft_ammo_*_bulk.lua` files plus the ammo defined inline in weapon-pack bulk files (shotguns, pistols, snipers, SMGs, ARs, explosives).
3. **Shortnames**: deduplicated by shortname; a collision is resolved in favour of the EFT SHARED pack (workshop id 2917343547).
4. **Calibre**: explicit overrides for shotshell pellets and other sub-calibre loads; otherwise the `eft_ammo_<token>` category token maps through `CaliberByToken` (with `_saiga12only` / `_nonubgl` suffix normalisation). Buckshot pellet diameter is parsed from the attachment name (e.g. `12/70 5.25mm buckshot` -> 0.525 cm); slugs keep the bore calibre.
5. **Mass**, in order of confidence: first `<n> gram` in `ATT.Description`; else `<n> grain` / `<n>gr.` (grains x 0.06479891); else an explicit override for the few blocks with no data at all; else for shotshells `(weight - C.ShellCaseMass[bore]) / ATT.Num`; else `weight * C.MassRatioByToken[token]` (falling back to `C.Defaults.FallbackMassRatio`). Multi-projectile blocks without `ATT.Num` use the documented override count (40x46 M576: `NumUBGL` = 5). Everything is clamped to the bridge's projectile-mass interval (0.0002 - 0.12 kg).
6. **Pellet sanity cap**: EFT cartridge weights for shotshells include much more than the shot load (the 5.25 mm shell is listed at 44 g while its 8 pellets weigh ~7 g total), so the raw shell formula over-estimates small pellets several-fold. Heuristic **pellet** masses are therefore capped at the mass of a solid lead sphere of the derived pellet diameter; the uncapped formula value is still recorded in the CSV and listed below for review. Slug loads keep the formula value. Flechette and steel-tack loads use explicit per-dart masses instead.
7. **Type** (`AP`/`HP`): `HP` when the name/description says hollow (point), HP, soft point, SP, RIP, expansive, Warmageddon, QuakeMaker, Predator, Devastator, fragment or segmented; or when penetration power <= 10; or for non-slug shotshell pellets. Two narrow guards applied: "SP-6"/"SPP"/"SP13" (Russian *special cartridge* designations, not soft points) are not matched as SP, and "controlled fragmenting projectile" paired with "armor-piercing" (Russian AP design wording) is not treated as expansion. Otherwise AP.
8. **Validation**: every entry must have a known token, cal > 0, 0.0002 <= mass <= 0.12 kg and type AP/HP; the total entry count must be 150 or more. The generator exits non-zero on any violation.

## Projectile type rules and counts

- AP: 129 entries; HP: 68 entries.

HP is set for expanding/soft/frangible designs, low-penetration rounds (shotshell pellets, weak pistol loads) and the 40x46 HE/HEDP grenades (their generated stats are commented out in the pack; they are explosive fragmentation rounds). AP is everything else, including shotshell slugs/sabots/flechettes and ordinary rifle/pistol FMJ. This deliberately does not use `penetrationPower < 25` as the HP test: ordinary 5.56/5.45 FMJ sits in the low 20s and is not a hollow point.

## Validation and deterministic regeneration

Generator validation (all enforced, non-zero exit on failure):

- 197 entries (required: 150+)

- every entry has a known `eft_ammo_<token>` category token

- every entry has `0 < cal` and `0.0002 <= mass <= 0.12` kg

- every entry has `type` AP or HP and a non-empty shortname

- output sorted by shortname, numbers formatted with a fixed routine


Deterministic re-run check: `python3 tools/gen_eft_ammo_map.py` twice; the `.lua`, `.md` and `.csv` outputs are byte-identical (sha256 of the Lua map is recorded above). `python3 tools/gen_eft_ammo_map.py --check` exits 0 when the checked-in files match a fresh generation.

LuaJIT sanity check (the map file only assigns tables, so it can be loaded outside GMod):

```sh
luajit -e 'dofile("Arc9AceBridge/lua/arc9_ace_bridge/sh_config.lua"); dofile("Arc9AceBridge/lua/arc9_ace_bridge/sh_eft_ammo_map.lua"); local n=0 for _ in pairs(ARC9ACE.EFTAmmoMap) do n=n+1 end print("entries", n)'
```
Expected output: `entries 197`.

## Known caveats

- The pack's shotshell weights are not physically consistent with the pellet loads; the shell formula can only be a starting point. Pellet masses are capped at the lead-sphere mass for the derived diameter and every heuristic value is listed above for review. Slugs keep the raw formula result (a 12/70 slug is exported around 45 g).
- 40x46 rounds have no generated stats in the pack (`table.Merge` is commented out), so their masses are explicit overrides: EFT lists the HE/HEDP rounds at 0.23 kg, which the bridge clamps to its 0.12 kg projectile-mass ceiling; M576 uses its documented 24-grain pellet.
- `eft_ammo_556_bb` is the Airsoft 6 mm BB attachment. It exists in the pack but is unused in Tarkov; it maps to 0.6 cm / 0.2 g.
- The 20/70 "Elephant killer", "explosive" slug and "Flechetta Plus" rounds are removed-from-game event items with no generated stats; their masses are documented estimates (20 ga slug ~18 g, flechette dart 0.47 g).
- Calibre/mass cross-checks against EFT item data were used for the 23x75 Shrapnel pellets (8.5 mm), 12/70 flechette darts (2 mm / 0.47 g) and 40x46 M576 pellets (7 mm / 24 grain). They are hard-coded in the generator's override tables with comments.
- The bridge clamps projectile mass at 0.12 kg; the two 40x46 HE classes are therefore not physically accurate in-game.
